BTL Sync - بدون زیپ و بدون کپی دستی
=====================================

یک بار آماده‌سازی
1) Git را نصب کن (اگر نداری):  winget install --id Git.Git -e
2) مخزن را یک بار clone کن:     git clone https://github.com/PoMo007/BTL-Studio
   (بار اول که push کنی مرورگر باز می‌شود و به GitHub لاگین می‌کنی. فقط یک بار.)

استفاده‌ی هر روز
1) tools\Pack.bat را دابل‌کلیک کن. متن زمینه کپی می‌شود. آن را در چت هر AI پیست کن و تسکت را بنویس.
   (اگر فایل مشخصی لازم است:  Pack.bat agent\main.py)
2) AI در آخر یک patch می‌دهد (یک بلوک کد). کپی‌اش کن.
3) tools\Sync.bat را دابل‌کلیک کن. خلاصه‌ی تغییرات را نشان می‌دهد، y بزن. خودش commit و push می‌کند.
4) اگر چیزی خراب بود: tools\Sync-Undo.bat آخرین تغییر را برمی‌گرداند.

نکته‌ها
- Sync فقط متن فایل‌ها را می‌نویسد، هیچ کدی از patch اجرا نمی‌شود.
- فایل‌های مخفی/پروژه/صدا (config.json، .flp، .wav، ...) را رد می‌کند.
- اگر patch ناقص کپی شده باشد (بدون END) رد می‌شود و چیزی عوض نمی‌شود.
- اگر AI به GitHub وصل است، لازم نیست از اینها استفاده کنی.
